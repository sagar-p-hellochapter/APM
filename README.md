# Chapter PM Assistant Portal

A mobile-first, live PM assistant portal for Chapter Renovation — pulls real-time
project data from the HUB (via MCP) and Outlook, surfaces the day's to-dos, payment
and change-order status, and drafts client/reminder emails for review.

- **Plan & decisions:** [`ARCHITECTURE.md`](./ARCHITECTURE.md)
- **Skills:** [`skills/`](./skills) — discrete, composable steps in the data pipeline.
- **Config you maintain:** [`config/`](./config) — `settings.json`, `subs.json`.
- **Live data layer:** `data/` — regenerated by the skill runner; the committed
  snapshot is the offline fallback.

## Regenerate the project data

```bash
node skills/hub-project-aggregator/normalize.mjs --ref $(date +%F)
```

(The skill runner makes the HUB MCP calls and writes `data/raw/hub-snapshot.json`
first; see each skill's `SKILL.md`.)

## Email safety

The portal **never** emails clients, subs, or vendors — everything external is
draft-only for the PM to send from Outlook. The only address the system may auto-send
to is the PM's own (`config/settings.json → email.selfSendAllowlist`).
